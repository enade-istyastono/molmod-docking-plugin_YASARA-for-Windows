# MOLMOD Docking Plugins for YASARA Structure for Windows 11
YASARA Structure plugins for performing protein-ligand docking simulations. An improved version from <a href="https://molmod.id/yasara/molmod-yasara-plugins.zip">the 2023 version</a>.

<p></p>
<p><b>Dependencies:</b>
<br>1. YASARA Structure for Windows (minimum version: 25.1.13)
<br>2. Ubuntu (tested working version: 24.04) in Windows Subsystem for Linux.</p>  
<p></p>
<p><b>Installation:</b> Open YASARA Structure and run the install.mcr file from the software. To uninstall the plugins, run the uninstall.mcr file from the software.</p>

<p><b>Note:</b> <a href="https://molmod.id/saas/ys-plug_docking">Click here</a> to learn how to use this plugin.</p>

# Update on August 8, 2026
Since YASARA Structure version 26.4.17, BOLTZ-2 has been incorporated, and the macro dock_run.mcr now requires explicitly mentioning the docking method. Otherwise, an interactive pop-up will ask for the method. Thus, we updated this plugin by copying the macro and explicitly specifying 'VINA' as the docking method. For users with YASARA Structure version 26.4.17 and above, the plugin should be version 0.0.4 or above.
